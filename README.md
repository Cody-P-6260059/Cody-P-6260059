#### Remoto — McGill CodeJam 15 Winner

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![Cloudflare](https://img.shields.io/badge/Cloudflare-F38020?style=flat-square&logo=cloudflare&logoColor=white)
![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white)

> Control your home PC from any device using plain text commands. Remoto captures your screen, runs OCR to understand what's on it, routes your command to the best LLM (Gemini, GPT-4.1, or Claude), and executes actions via keyboard and mouse automation, all streamed live to your phone.

- 🤖 **Smart model routing** picks the optimal LLM per task, with 12 custom tools for clicking, typing, hotkeys, launching apps, and more
- 📡 **Real-time screen streaming** via FFmpeg + MediaMTX + Cloudflare tunnels
- 🧠 **Persistent memory** learns your workflows across sessions so "start work mode" just works

🔗 [View on GitHub](https://github.com/muhammadbalawal/remoto)
